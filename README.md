# Flipster — Flip Ninja Rival Run

A fast-paced, mobile-first endless runner: a black ninja auto-runs, one tap jumps, and speed ramps up over time. Supports solo running and 2-player real-time matches where players compete for the highest score.

## Features

- **One-tap controls**: Tap anywhere or press Space to jump.
- **Track flipping**: Flip gravity to run on the ceiling or floor.
- **Dynamic obstacles & power-ups**: Spikes, spinning blades, lasers, shields, and speed boosts.
- **Online 2-player rivalry**: Live score tracking and room codes powered by Supabase.
- **Smooth 60/120 FPS canvas animation**: Handcrafted per-frame registration for fluid pixel-art animation.
- **Telegram Mini App ready**: Built-in viewport expansion and orientation management.

## Development

Prerequisites: Node.js (v18+) or Bun.

```sh
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
